The vector icon art
===================

Version:  the sets of 12 October 2026
From:     tools/iconart in BOX's sources
Used by:  Resources.Themes: the four vector icon sets (BOX, Win2K, Pinstripe
          and the Cube plinths), as VecIcons files loaded by *IconSprites.
          The icons are composed by BOX's tools from the art below; the
          composition and the tools are BOX's own, under BOX's licence, and
          each source keeps its licence
Licence:  MIT (Haiku, Fluent); public domain (Tango); Apache License 2.0
          (the Acorn art); SIL Open Font License 1.1 (the Noto Sans
          outlines)

src/acorn is RISC OS 5's own icon art, from the 5.30 Acorn theme's
Sprites11, traced to vectors: it is RISC OS Open's under the Apache License
2.0, as the file RISCOS says, and is the same art the bitmap themes already
carry.

Haiku's logo and its leaf are trademarks of Haiku, Inc., and are not used.

font/glyphs.json holds outlines taken from Noto Sans Bold, used to set the
type tags on file icons; the font itself is not shipped.

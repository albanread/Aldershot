Haiku's icon library
====================

Version:  Haiku's tree, taken 12 October 2026
From:     https://github.com/haiku/haiku (src/libs/icon)
Used by:  VectorIcons in /init: the renderer that draws vector icons
          (ports/vicon/haiku/icon, with
          ports/vicon/haiku/shared/AutoDeleter.h) -- the HVIF reader, the
          icon model (shapes, paths, styles, gradients, transformers) and
          IconRenderer; and tools' vicon, the same code on the host. BOX's
          changes to it are under Haiku's licence
Licence:  MIT

Haiku's files are kept as Haiku has them, so that an icon draws exactly as
Haiku draws it. BOX's only changes, each marked BOX: in the source, hold a
damaged icon's numbers inside the ranges the arithmetic is defined for, so
that an icon file from anywhere can be read safely; they change no real
icon's rendering. ports/vicon/shim is BOX's own, under BOX's licence:
stand-ins for the Haiku kit classes the library calls.

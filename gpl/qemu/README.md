# QEMU

The Mac releases run BOX in QEMU 11.1 (GNU GPL 2; some parts under other free licences). Its full source, as built into the releases, is at [github.com/albanread/qemu-intel-mac](https://github.com/albanread/qemu-intel-mac); the releases of 8 October 2026 (Intel Mac 2026.10.08, Apple silicon 2026.10.08.3) are built from its commit `e0d62a0`, which keeps the window where the user puts it; the Apple silicon release 2026.10.08.2 was built from `de5ba4a`. The licence is in `BOX.app/Contents/Resources/qemu/COPYING` and in [LICENSES/box/QEMU.txt](../../LICENSES/box/QEMU.txt).

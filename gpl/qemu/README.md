# QEMU

The Mac releases run BOX in QEMU 11.1 (GNU GPL 2; some parts under other free licences). Its full source, as built into the releases, is at [github.com/albanread/qemu-intel-mac](https://github.com/albanread/qemu-intel-mac); the releases of 18 October 2026 (Apple silicon and Intel Mac, 2026.10.18.3) are built from its commit `dd0e25a` (each press and release carries its own place), after `6398bb6`, in which the window draws the desktop's windows itself and !Browser's pages are the Mac's own WebKit; the releases of 11 October 2026 (2026.10.11.2) were built from `15496d1`, which adds the backdrop's scenes from shader files and reads RISC OS sprite wallpapers; the releases of 8 October were built from `e0d62a0` (and the Apple silicon 2026.10.08.2 from `de5ba4a`). The licence is in `BOX.app/Contents/Resources/qemu/COPYING` and in [LICENSES/box/QEMU.txt](../../LICENSES/box/QEMU.txt).

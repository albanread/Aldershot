# QEMU

The Mac apps run the BOX in QEMU 11.1 (GNU GPL 2; some parts under other free
licences), built for macOS 14 with the BOX's Metal display. Its full source,
the build the apps carry, is public:
[github.com/albanread/qemu-intel-mac](https://github.com/albanread/qemu-intel-mac).
Its licence is in each app, `BOX.app/Contents/Resources/qemu/COPYING`, and in
[../../LICENSES/box/QEMU.txt](../../LICENSES/box/QEMU.txt).

# QEMU

The Mac releases run BOX in QEMU 11.1 (GNU GPL 2; some parts under other free licences). Its full source, as built into the releases, is at [github.com/albanread/qemu-intel-mac](https://github.com/albanread/qemu-intel-mac); the Apple silicon release of 8 October 2026 is built from its commit `de5ba4a`. The licence is in `BOX.app/Contents/Resources/qemu/COPYING` and in [LICENSES/box/QEMU.txt](../../LICENSES/box/QEMU.txt).

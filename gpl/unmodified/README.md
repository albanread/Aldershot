# Copyleft code the BOX uses unchanged

These are shipped as their upstream builds, unchanged. Their source is where it
came from:

* **glibc 2.41-12+deb13u4** and the **GCC 14.2.0-19 runtime** (libstdc++,
  libgcc), which *Mojo's compiler runs on: Debian's packages, unchanged. Source:
  <https://snapshot.debian.org/package/glibc/2.41-12+deb13u4/> and
  <https://snapshot.debian.org/package/gcc-14/14.2.0-19/>.
* **FreeFont 20120503** (GNU GPL 3 or later, with the font exception), among
  RISC OS 5.30's fonts as RISC OS Open distribute them: <https://www.gnu.org/software/freefont/>.
* **The WPE root**, the web browser's Linux userland: Debian's packages
  (forky), unchanged. Each package's version and source package are in
  [../../LICENSES/wpe](../../LICENSES/wpe/); its source, at that version, is at
  `https://snapshot.debian.org/package/<source>/<version>/`.

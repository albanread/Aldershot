# publish

This folder records the provenance of every C and header file built into `/init`.
The CSV files go here, one for each area of the source.
Each entry gives a file's kind (own, RISC OS Open, other open source or vendored), where it comes from, its licence and the evidence.
The tools used are in `tools/publish/`.

## Licence

Each source file names its licence in its header.
The BOX project asserts no ownership of translated code.

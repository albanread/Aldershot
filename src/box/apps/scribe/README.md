# Scribe

!Scribe is a word processor. It opens Word documents (`.docx`, and the older `.doc`) and saves them as `.docx`. It has fonts, paragraph styles, headers and footers, tables and a spelling check, and it can export PDF, Rich Text, OpenDocument, plain text and HTML. Its engine is built on WordCraft.

`Scribe.mojo` is the application. It needs the shared shell, `../shell/rosapp.mojo`.

# Draft

!Draft is a Markdown editor. It shows a Markdown file as a page, with headings, tables, pictures, coloured code, and each fenced `mermaid` block drawn as a diagram, and it edits the source; a button swaps the two. It can export text, a Draw file, a web page or a sprite. Its engine is our own, over selkie's Mermaid grammars.

`Draft.mojo` is the application. It needs the shared shell, `../shell/rosapp.mojo`.

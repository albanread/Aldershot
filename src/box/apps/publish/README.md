# Publish

!Publish lays out pages. A document is pages with frames on them: a text frame holds a story that can run on from one frame to another, a picture frame holds a picture, and boxes, ovals and lines are shapes. It has master pages, paragraph styles and text that wraps round frames. It saves its own documents (type &A9B), opens IDML files, and exports PDF, EPUB, a web page, IDML and PowerPoint, a story's text, and a page as a Draw or ArtWorks file or a picture. Its engine is built on DesignCraft.

`Publish.mojo` is the application. It needs the shared shell, `../shell/rosapp.mojo`.

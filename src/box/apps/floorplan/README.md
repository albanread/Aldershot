# FloorPlan

!FloorPlan draws the plan of a house, a flat or a small office: walls, the doors and windows in them, rooms with their names and areas, furniture and fittings, dimensions and labels, drawn to scale on an A4 or A3 sheet. Plans are kept in their own files (type &A9A), and can be exported as Draw files, PDF, DXF, SVG and PNG. Its engine is built on CADCraft's geometry, drawing and file formats.

`FloorPlan.mojo` is the application. It needs the shared shell, `../shell/rosapp.mojo`.

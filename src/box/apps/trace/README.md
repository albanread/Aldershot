# Trace

!Trace is a drawing program. It opens and saves SVG drawings, opens PostScript, EPS, DXF and Illustrator files, and imports Draw and ArtWorks files. It has the pen, shapes, text, layers, gradient fills and a grid, and it can export Draw, ArtWorks, PNG, PDF, JPEG, EPS and DXF. Its engine is built on VectorCraft.

`Trace.mojo` is the application. It needs the shared shell, `../shell/rosapp.mojo`.

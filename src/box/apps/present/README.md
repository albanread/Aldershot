# Present

!Present is a presentation program. It opens and saves PowerPoint presentations (`.pptx`), edits their slides, and shows them on the whole screen. It has text, shapes, tables and themes, and it can export PDF, or a slide as a PNG or JPEG picture. Its engine is built on DeckCraft.

`Present.mojo` is the application. It needs the shared shell, `../shell/rosapp.mojo`.

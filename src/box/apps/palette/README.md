# Palette

!Palette is a paint program. It opens PNG, JPEG, TIFF, GIF and BMP pictures, and saves PNG. It has brushes, a spray and a smudge tool, selections by shape, by colour or by subject, fills and gradients, colour corrections, effects and red eye removal, and it can export JPEG, TIFF, GIF, BMP, WebP and Photoshop files. Its engine is built on PhotoCraft.

`Palette.mojo` is the application. It needs the shared shell, `../shell/rosapp.mojo`.

# Ledger

!Ledger is a spreadsheet. It opens and saves Excel workbooks (`.xlsx`) and CSV files. It has a formula bar, number formats, sorting, fill, several sheets and a find command, and it can export CSV and HTML. Its engine is built on gridcraft.

`Ledger.mojo` is the application. It needs the shared shell, `../shell/rosapp.mojo`.

# Apps for BOX

Apps developed for BOX will be placed here.

- [Appearance](appearance/) sets the desktop's look: the theme, the windows and the wallpaper.

The ROSAPPS applications are written in Mojo. Each one is the shared [shell](shell/) with its own settings, over an engine written in Rust. Only the Mojo source is published here; the engines of Micropolis and Tower are published in repositories of their own, with the simulations they run.

Documents:

- [Scribe](scribe/) is a word processor for Word documents.
- [Ledger](ledger/) is a spreadsheet for Excel workbooks and CSV files.
- [Folio](folio/) is a PDF reader and editor.
- [Present](present/) is a presentation program for PowerPoint files.
- [Publish](publish/) lays out pages.
- [Draft](draft/) edits Markdown with diagrams in it.

Pictures:

- [Trace](trace/) is a drawing program for SVG drawings.
- [Palette](palette/) is a photo editor for PNG, JPEG and other pictures.
- [Canvas](canvas/) is a painting program.
- [FloorPlan](floorplan/) draws plans of houses and small offices.

Sound, programs and work:

- [Studio](studio/) is a multitrack studio.
- [Code](code/) is the programmer's editor.
- [Workflows](workflows/) makes Tcl workflows.

Games:

- [Micropolis](micropolis/) is the city simulation.
- [Tower](tower/) is a tower-building game.

# Canvas

!Canvas is a painting program: you start with an empty canvas and make a picture. It has thirty-six brushes in four groups (general, dry media, wet media and special effects), a pencil, an airbrush, a smudging wet brush that picks up paint from the canvas, an eraser and painting symmetry. The properties pane holds everything about the brush in use. The box has a mouse and no tablet, so the pointer's speed stands in for pressure. It saves PNG pictures. Its engine is built on PhotoCraft's brush engine.

`Canvas.mojo` is the application. It needs the shared shell, `../shell/rosapp.mojo`.

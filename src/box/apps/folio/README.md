# Folio

!Folio is a PDF reader and editor. It opens PDF documents and can add notes, highlights, ink and rectangles, and insert, delete, move and turn pages. A picture or a text file dropped on it becomes a new PDF. It can export a document's text, or a page as a sprite. Its engine is built on PDFCraft.

`Folio.mojo` is the application. It needs the shared shell, `../shell/rosapp.mojo`.

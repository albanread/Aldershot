# Code

!Code is the programmer's editor. One window holds many files, as tabs. Mojo, C and C++, BBC BASIC, Lua, Tcl and the other languages the box has are coloured as they are written; Mojo, C and C++ are backed by their language servers, which mark errors as you type and offer completion, information on a name, renaming, going to a definition, references, formatting and quick fixes. It builds and runs a single file or a project, and its debugger sets breakpoints and steps through the program.

`Code.mojo` is the application, and `LuaDebug,18c` is the small Lua script the debugger runs Lua programs under. It needs the shared shell, `../shell/rosapp.mojo`.

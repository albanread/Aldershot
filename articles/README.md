# Articles

Technical articles about BOX (RISC OS on a Linux kernel, translated to
C). They follow the style of the RISC OS Programmer's Reference Manuals
and describe the code as it currently works. Each article can be read on
its own.

| 3 October 2026 | **Concurrency and Parallelism** | How BOX runs RISC OS's co-operative tasks on a many-core machine: each task a Linux thread sharing one arena, the baton passed at `Wimp_Poll`, task threads kept on one core, the personality lock in place of "interrupts off", Linux helpers as the only parallel work, why tasks cannot run in parallel, and how modules and applications (Workers) still use the other cores. | [Concurrency and Parallelism](concurrency-and-parallelism.md) |

| 3 October 2026 | **Is BOX an Emulator?** | No: BOX is a port of RISC OS to C, running on Linux, and runs only translated or compiled code.
